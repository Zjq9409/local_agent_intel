# Local AI agent of Intel
## qwen-code安装方法
如果之前安装过qwen-code，请先卸载
```bash
npm uninstall -g @qwen-code/qwen-code
```

```bash
cd qwencode
npm install
npm install -g .
```
### 配置qwen-code的配置文件
将settings.json复制到C:\Users\${USER}\.qwen目录下
### 启动qwencode
新建一个worspace目录，将.env文件放置到该目录下,在该目录下命令行输入qwen即可启动
